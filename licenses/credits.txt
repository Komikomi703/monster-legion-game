# MONSTER LEGION クレジットと素材利用条件

| 素材・ライブラリ | 制作元と生成方法 | 利用条件 |
| --- | --- | --- |
| ゲームコード、UI、タイトルロゴ、アプリアイコン | 本プロジェクト。画素単位で定義した字形と図案 | MIT。著作権表示と許諾文を同梱 |
| 戦闘キャラクター、図鑑の肖像、地形、エフェクト | 本プロジェクト。Canvasで輪郭と色面を描き、戦闘開始時にテクスチャ化 | MIT。著作権表示と許諾文を同梱 |
| 森のキービジュアル、全10ステージの景観 | 本プロジェクト用に内蔵ImageGenで新規生成。WebP変換とトリミングを実施 | 本プロジェクトの権利の範囲でMITと同条件で利用・改変・再配布可 |
| BGM・効果音 | 本プロジェクト独自の旋律とWeb Audioの合成音。外部サンプル音源の使用なし | MIT。音型は src/battle/audio.ts に収録 |
| Phaser 3.90.0 | Richard Davey、Phaser Studio Inc. | MIT。配布物に licenses/phaser.txt を同梱 |
| EventEmitter3 | EventEmitter3 contributors | MIT。配布物に licenses/eventemitter3.txt を同梱 |
| 開発・テスト | TypeScript、Vite、Vitest、Playwright、pnpm | 開発用依存関係の個別ライセンスはインストールした各パッケージに同梱 |

書体は端末の標準フォントを使います。タイトルロゴには独自のピクセル字形を使っています。Webフォントや音楽配信サイトへの接続はありません。

生成背景の最終指示と保存先は [アート制作記録](docs/art-direction.txt) に収録しています。
